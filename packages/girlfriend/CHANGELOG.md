# CHANGELOG — girlfriend

This is the changelog for the `girlfriend` pis package. It is independent of
the pis package manager's own changelog.

## 0.1.0 — 2026-09-12
- Initial release.
- `roast()` — prints a random roast line about having no girlfriend.
- `rate()` — rates your chances of getting a girlfriend (always terrible).
- Script entry points: `roast = "girlfriend:roast"`, `rate = "girlfriend:rate"`.
